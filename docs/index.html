Native C# for RISC-V zkVMs.

bflat-riscv64 compiles C# to fully static RISC-V ELF binaries. A binary runs in a zkVM prover (ZisK, SP1, OpenVM or Airbender), under qemu-riscv64, or on RISC-V64 Linux. The same source builds for each target.

your shell — bash

What it is

A compiler driver for .NET NativeAOT, with the parts that a zkVM needs.

The original bflat compiles C# to native code with NativeAOT, and its binaries are dynamically linked. A zkVM cannot load those dependencies. This fork adds zkVM platforms that packages define, fifteen modules, ILC-stage substitutions and post-link tools. It does not change the upstream sources.

Five zkVM platforms

zisk, sp1 and openvm on riscv64, airbender on riscv32, and zisk_sim for a ZisK-shaped binary that runs in QEMU or on real hardware. Its bflat-* package defines each platform. bflat itself defines none.

Fifteen modules

Small C, C++ and assembly objects go into the link, and --wrap= sends calls to them. One module gives ILC its substitutions. No upstream code is patched.

Per-platform memory maps

Each package carries the linker script, the entry point and the exit protocol of its zkVM, in its platform/ directory.

Post-link tools

patch_elf.py rewrites the ELF for the loader of ZisK, SP1 and Airbender; flat_image writes the ROM images that Airbender loads.

NuGet integration

--extlib reads NuGet packages that have a bflat manifest, for example the precompiled native library libziskos.

Used in production

bflat builds Nethermind's StatelessExecutor, an Ethereum state-transition function. zk-testing tracks its proof time on each change.

Foundation

A sibling project builds the runtime that bflat uses.

dotnet-riscv builds the runtime and its cross rootfs for the zkVM constraints: no compressed instructions, no FP, and one ABI for all objects. It publishes them as release assets. The bflat build downloads and unpacks them.

.NET: dotnet-riscv

Takes the upstream .NET VMR at a release branch and builds it for the target ISA with its riscv64 patches. It publishes CoreLib, the runtime libraries and ILCompiler as a signed release. bflat uses the .NET 11 build, for riscv64, riscv32 and linux-x64.

An official .NET build.

The runtime is upstream .NET: the dotnet/dotnet VMR at a release branch, built with upstream's own build system. bflat applies the zkVM changes outside the runtime: at ILC time, at link time and after the link. The runtime carries a riscv64 patch series for upstream, and code-quality patches for the zkVM guests on top.

bflat pipeline

From .cs source to a zkVM-ready ELF in four stages.

bflat runs four stages. The BuildCommand files in src/bflat/ drive them. The compile from C# to an object uses Microsoft's stock NativeAOT. The changes of this repository apply at link time and after.

{% include pipeline-diagram.html %}
  1. 01

    Microsoft's NativeAOT (ILC) emits an object

    Stock ILC compiles C# to one RISC-V ELF relocatable. It contains the managed code, the type-system metadata and the module init tables. The upstream compiler has the same tests as the rest of .NET.

  2. 02

    ld.lld links the binary statically

    --whole-archive pulls in the module objects. --wrap=symbol sends each musl, compiler-rt and runtime call that a module replaces to the module.

  3. 03

    Post-link steps rewrite the image

    Each platform lists its own steps. zisk fixes .init_array and .tdata for its loader and trims .bss. sp1 changes FENCE and zero padding into NOPs. airbender rewrites the instructions that its RV32 machine cannot run, and writes flat .bin/.text images. zisk_sim and openvm have none.

  4. 04

    Run and prove on a zkVM

    The output is one ELF. It runs in a zkVM prover (ZisK, SP1, OpenVM or Airbender). The zisk_sim build runs under qemu-riscv64 or on RISC-V64 Linux. The same source builds for all of them.

Architecture

What this repository contains.

This repository has the compiler driver, the modules and the post-link tools. The zkVM platforms are in their bflat-* packages. dotnet-riscv builds the .NET runtime against an Alpine cross rootfs from upstream's own tooling, with musl rebuilt for the base ISA. The bflat build downloads its release assets. No part of the stack emits compressed, atomic or FP instructions. The code that bflat compiles and links uses the soft-float lp64 ABI (ilp32 on riscv32).

{% include architecture-stack.html %}
ubootstrap

Runtime entry point. It calls RhInitialize, registers the managed-code range, runs the module initialisers and jumps to __managed__Main.
pal

Deterministic OS calls: getenv, sched_*, mmap and the clock. The malloc family on a bump allocator, and a vfprintf with no FP.
rhp

Runtime helper replacements: P/Invoke frames, allocation fast paths, the console, and the exception policy of --remove-eh.
rhp_native

Hand-written RISC-V assembly for rv64 and rv32. Each GC write barrier is a plain store, because uGC has no card table.
tls

Minimal thread-local storage without the ELF code of musl. It copies .tdata into a static block and answers __tls_get_addr.
eh

Synthetic program headers. Answers dl_iterate_phdr, so the unwinder finds its tables in an image with no loader.
nofp

Traps the soft-float builtins and libm functions that must not run. A guest that calls one stops with an error. The exact libm operations run.
noos

Defines the OS calls of the Unix PAL of the runtime, before musl. It links on the platforms with no OS: SP1, OpenVM and Airbender.
nothread

Single-hart replacements for musl's locking and thread primitives, on platforms with no atomics.
rng_stupid

A deterministic PRNG for RandomNumberGenerator and the random entry points of the runtime. A proof must be reproducible.
gs_cookie

Sets the stack cookie to the constant 0. A zkVM has no entropy and no page protection.
stdcppshim

The C++ runtime parts that the NativeAOT runtime needs: operator new and delete on malloc.
rust_sys

Connects the allocator hook of the zkVM Rust runtimes (sys_alloc_aligned) to the shared bump heap.
ugc-zero

uGC, a GC that never collects, in place of the built-in GC. A proof run is short, and its working set is known.
guest_subst

ILC-stage substitutions and invariant feature switches for single-hart, OS-less guests. No native object.
zkVM platforms

The assembly _start, the linker script and the exit protocol. They are in the bflat-* package of each zkVM.

Verification

Checks that fail before the prover runs.

CI runs on each push and pull request in this repository. It checks the contracts on the native modules and runs the C# analyzers and unit tests on the driver. It runs the module unit tests on the real ISA under qemu, fuzzing and a CBMC proof of the allocator. Then it builds the Docker images for riscv64 and riscv32 and links a guest for each zkVM target. The riscv32 guests run on the Airbender simulator. A pull request also runs the bflat-ts suite with its own image on the zk-testing host. The suite includes Nethermind's StatelessExecutor.

{% include verify-flow.html %}

Repository CI

GitHub Actions build-riscv64.yml runs the contract gate, the analyzers, the unit tests, fuzzing and the CBMC proof. Then it builds each module and the driver from source, in two legs: riscv64, and riscv32 with the Airbender run.

bflat-ts on each pull request

CI pushes the image of the pull request to GHCR. The simple test of bflat-ts runs with it first. Then the full suite runs on each zkVM.

End-to-end proofs

The zk-testing dashboard shows the bflat-ts results with proof timings, and a public badge. The results include the Nethermind StatelessExecutor.

Quick start

One command, source to ELF.

With a built bflat in your $PATH:

~/work/hello — bash 
# The ZisK platform and its precompile library, from a signed GitHub release
$ bflat build hello.cs --arch riscv64 --os linux --libc zisk --no-pie \
      --extlib https://github.com/NethermindEth/bflat-libziskos:v1.4.0-alpha.153

# The same source, for the simulator target
$ bflat build hello.cs --arch riscv64 --os linux --libc zisk_sim --no-pie \
      --extlib https://github.com/NethermindEth/bflat-libziskos:v1.4.0-alpha.153
$ qemu-riscv64 ./hello
Hello world!

# Airbender, on riscv32: the assets of a bflat-airbender release, downloaded,
# and a bflat built with the riscv32 target
$ bflat build hello.cs --arch riscv32 --os linux --libc airbender --no-pie --no-pthread \
      --extlib bflat-airbender/libairbender.bflat.manifest
$ ls hello hello.bin hello.text
